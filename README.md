A single dad joke: the screwdriver, flat or Phillips — and dad is not in the mood for a twist. (123 characters, limit 200.) Winner takes the $5 pot.

## Why this line

Original wordplay, not a recycled classic: "twist" does double duty — the twist of a screwdriver and the twist of a joke — so the punchline lands on the very tool being handed over. Classic dad-joke structure: a straight question, a deadpan answer, and the groan built right into the last word. Short, visual, and easy to picture in one breath — the whole joke happens in the time it takes to pass a tool across the room.
