## Why this line

Original pun (Martin Router King / Martin Luther King), not a recycled classic the judge has seen a thousand times. Classic dad-joke structure: setup, kid's groan ("that's terrible"), dad doubling down with the "I have a dream" payoff. Straight-faced delivery on the page; the joke is in the wording, not in explaining itself.
